# 🧰 Toolbox365

> A toolbox for developer easiness. Here we are building the following features:

---

## 🔧 Developer Tools

**📋 JSON Formatter / Validator / Minifier**
Paste raw JSON to format it with indentation, validate its syntax and highlight errors, or strip all whitespace to minify it.

---

**🔑 UUID Generator**
Generates RFC-compliant UUID v4 strings to use as unique identifiers anywhere in your code.

---

**🔐 Password Generator**
Generates cryptographically random passwords with configurable length and character sets.

---

**🔒 Base64 Encoder / Decoder**
Converts plain text to Base64 and back — useful for encoding tokens, images, or binary data in text form.

---

**🌐 URL Encoder / Decoder**
Encodes special characters in URLs and decodes them back to readable text.

---

**#️⃣ Hash Generator**
Generates MD5, SHA-1, and SHA-256 hashes from any input string.

---

**🪙 JWT Decoder**
Decodes and inspects a JWT token's header, payload, and signature without needing a backend.

---

**🔍 Regex Tester**
Tests a regular expression against input text with live match highlighting.

---

**⏰ Cron Expression Generator**
Builds cron schedule expressions visually and explains in plain English when they will run.

---

**🗄️ SQL Formatter**
Takes messy SQL queries and returns them formatted with proper indentation and keyword casing.

---

**🎨 Color Converter**
Converts color values between HEX, RGB, and HSL formats instantly.

---

**🕐 Timestamp Converter**
Converts Unix timestamps to human-readable dates and vice versa, with timezone support.

---

**📊 Diff Viewer**
Pastes two blocks of text and shows a line-by-line diff highlighting exactly what changed.

---

**📄 YAML Validator / YAML↔JSON Converters**
Validates YAML syntax and converts between YAML and JSON formats.

---

**🏷️ XML Formatter / Validator**
Formats and prettifies XML markup, or validates it for syntax errors.

---

**📊 CSV Parser / CSV↔JSON Converters**
Parses CSV data into a visual table, or converts between CSV and JSON.

---

**🌍 HTML Encoder / Decoder / Formatter / Minifier**
Encodes HTML entities, decodes them, prettifies HTML markup, or strips it down to minimal size.

---

**💅 CSS & JS Formatter / Minifier**
Formats or minifies CSS and JavaScript code for readability or production use.

---

**📝 Markdown Preview**
Writes Markdown and shows a live rendered HTML preview side by side.

---

**📡 HTTP Status Codes / MIME Types Reference**
Searchable reference tables for HTTP status codes and MIME types.

---

**🌍 IP Address Info**
Looks up geographic and network details about any IP address.

---

**🖥️ User Agent Parser**
Parses a browser user agent string into its browser, OS, and device components.

---

**🔢 Number Base Converter / Bitwise Calculator**
Converts numbers between binary, octal, decimal, and hex, or performs bitwise AND/OR/XOR/NOT operations.

---

**📟 ASCII Table / Unicode Lookup**
Browses the full ASCII character table or looks up any Unicode character by its code point.

---

**🔤 Escape / Unescape String**
Escapes special characters in strings for use in JSON or regex, and unescapes them back.

---

**🛡️ JWT Generator / RSA Key Generator / HMAC Generator / Bcrypt Hash**
Generates signed JWTs, RSA public/private key pairs, HMAC signatures, and bcrypt password hashes.

---

**🖼️ Color Palette from Image / PX↔REM Converters**
Extracts a color palette from an image URL, or converts pixel values to rem and back.

---

**📚 Tailwind / Git / Docker / Linux / NPM Reference**
Searchable cheat sheets for the most common commands in each tool.

---

**✅ Env Validator / Semver Validator / Semver Comparator / package.json Validator**
Validates `.env` file format, checks semantic version strings, compares two versions, and validates `package.json` structure.

---

**📐 OpenAPI Validator / GraphQL Formatter**
Validates OpenAPI/Swagger specs and formats GraphQL queries.

---

**🔄 SQL→JSON / Markdown→HTML / HTML→Markdown**
Converts between common data and markup formats.

---

**🧪 String Interpolation Tester / JSONPath Tester / XPath Tester**
Tests template literals, JSONPath expressions, and XPath queries against real data.

---

**🪝 Webhook Tester / API Response Formatter**
Sends test webhook payloads and formats/inspects API responses.

---

**🔬 CORS Checker / SSL Checker / DNS Lookup / Ping / Port Scanner**
Network diagnostic tools that run directly from the browser.

---

**🔗 URL Parser / Query String Builder / Robots.txt Generator / Sitemap Generator / .gitignore Generator**
Parses URLs into components, builds query strings, and generates common config files for any stack.
